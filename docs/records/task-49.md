# TASK-49 생활일 달력 조회

- 기록 화면에 목록/달력 전환(기본 목록). 달력은 `GET /api/records`(소유자 한정, TASK-16) 응답을 그대로 쓰는 읽기 전용 화면이며 서버 변경은 없다.
- 날짜 칸은 서버가 준 생활일(`lifeDate`)에만 놓는다. 제작·완성 시각은 쓰지 않으므로 늦게 완성된 영상도 원래 생활일에 표시된다.
- 기록 있는 날짜 → 해당 기록 상세(`/api/records/:id`). 기록 없는 날짜 → "기록이 없습니다" 안내만 표시하고 어떤 요청도 보내지 않는다(과거 기록 자동 생성 없음).
- 월 이동(이전/다음 달, 연도 경계 처리). 상세에서 돌아오면 보던 보기 방식·달을 유지한다.
- 범위 밖: 검색, 전체 내보내기, SNS 메타데이터.
- 검증: `npm test`(web 단위시험: 월 계산·생활일 배치), `DATABASE_URL=... node scripts/calendar-e2e.mjs`(PC·Android 에뮬레이션, 합성 데이터; 실기기 아님).
